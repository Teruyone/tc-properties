🌆 ハルト（エリア・利回り分析）

浜野駅（JR内房線）の立地評価

  • 1日乗降客数 約6,700人（JR東日本2023年度）→ 内房線の中でも小規模駅
  • 蘇我駅（京葉・外房・内房線 快速停車）まで1駅3分 → 蘇我経由で東京駅約45分
  • 千葉駅まで9分 → 千葉市中心部通勤圏として実用性あり
  • 駅徒歩2分（130m）は千葉圏で希少レベルの立地優位性

賃貸需要

  • JFEスチール千葉（旧川崎製鉄）の企業城下町 → 単身社員需要が底堅い
  • 千葉市中央区南部の1K相場: 5.8-6.5万円中心。浜野駅徒歩2分・新築設備なら6.5-6.7万円が妥当
  • スマサテ査定66,244円は新築プレミアム込みで相場上限に近い妥当水準

将来性・懸念

  • 千葉市中央区人口 約20万人（微増傾向）
  • 懸念: JFE製鉄所は将来の生産構造改革リスクあり（2020年に高炉1基休止）。単一大企業依存は10-20年スパンで需要変動要因
  • 22.77㎡は基準18㎡超だが「1Kとして最小クラス」。競合新築が大型化した場合の陳腐化早い
ハルトの率直な評価: 「基準外だが光る点多数・要検討」
駅徒歩2分×新築×単身需要地のトリプル揃い。スマサテ乖離▲0.7%は極めて健全。売主取引で仲介手数料470万円節約。
ただし総事業費1.57億円は基準+5,690万円超過。融資戦略の見直しが必須。

🏗️ 村田先生（建築士コメント）

※現場を見ないと断言はできませんが、資料から読み取れることをお伝えします。

構造評価

木造3階建・延床378.86㎡は木造3階建共同住宅として構造計算（許容応力度計算）必須。令和4年省エネ基準義務化（2025年4月〜）対象。竣工2027年3月なら省エネ基準適合が義務化後の物件として仕上がるので、この点は安心材料。3階建はルート2以上、接合金物・耐力壁バランス（4分割法）・ベタ基礎前提が肝心。

プランの合理性

22.20〜22.77㎡×14戸は浜野の1R需要（単身社会人）に合致。全15戸で駐車0台は千葉市郊外としてやや弱いが、駅徒歩2分でカバー可能。33.06㎡×1戸は3F角部屋想定なら家賃プレミアム設計として合理的。中央階段型は延焼・避難動線がシンプルで◎、共用廊下の採光・通風は現地確認必須。

直近リスク

  • 建築費10,200万円÷378.86㎡＝約26.9万円/㎡。木造3階共同住宅として妥当〜やや安め（相場27〜32万円/㎡）
  • 見積後の鋼材・木材・給湯器・電材の価格スライド条項の有無を契約書で必ず確認
  • 竣工が2027年6月以降にズレると初回満室が2027年繁忙期を外す

中期修繕リスク

  • 10年目: 外壁塗装300〜400万円
  • 15年目: 屋上防水80〜120万円／給湯器一斉交換180万円
  • 20年目: 給排水管点検／エアコン更新150万円
  • 30年サイクル総額: 1,000〜1,300万円（月3万円強/戸の積立目安）

法令適合性の確認ポイント

  • 確認済証・完了検査済証・住宅瑕疵担保保険付保証明の3点セット必須
  • 角地認定要件（2方向道路幅員）を確認
  • 容積率186.54%＜200%は前面道路幅員×0.4計算の可能性。前面道路4m未満なら再計算必要
  • 第一種住居地域＋準防火地域が濃厚（浜野駅前）。準防火なら木造3階は45分準耐火構造で対応
  • 日影規制・北側斜線・道路斜線のクリア図を確認

現地・実物確認事項

  • 完了検査済証と設計図書の整合（勝手な変更がないか）
  • 排水勾配（1/50以上）と共用廊下の防水立上り
  • 界壁・界床の遮音性能（1Kは隣室音がクレーム源）
  • 駐輪15台の動線（雨天時の入口混雑・防犯灯）
  • 給湯器・エアコン室外機の設置位置と更新性
  • サイディングのシーリング初期打設状況
村田先生の総合所感: 現場を見ないと断言はできませんが、駅徒歩2分・省エネ基準適合・実績銀行の融資内諾ありは新築案件として筋が良い。木造3階建は施工品質が寿命を決めるので、施工会社の実績（同規模木造3階建の竣工物件を3件以上）確認と第三者検査（配筋・上棟・完了の3段階）導入を強く推奨。竣工後のアフター2年点検も契約書で明文化を。

📢 キャプテンへの確認事項まとめ

最優先（買付前に必須）

  1. 前買主の融資不成立の理由は「買主属性」か「物件評価」か、売主から聞き出せますか？
  2. 売主（弊社）の建築実績・過去の同種物件の稼働状況は把握できますか？
  3. りそな/七十七の融資条件（金利・期間・自己資金）はキャプテン属性で内諾レベルまで取れそうですか？
  4. 1.57億円は基準超過。オリックス100%・35年が新築1.57億案件に通るか事前打診が必要。神奈川銀行(90%)の自己資金2,200万円は投下可能ですか？

契約条件（買付〜契約段階）

  1. 契約時に「建築確認取得を停止条件」「竣工遅延違約金」「建物完成保証」を入れられますか？
  2. 手付金の保全（宅建業法41条の保全措置）の設計は？未竣工売主物件は保全対象です
  3. 建築費10,200万円の上限固定（資材高騰時の増額NG条項）は契約書に入れられますか？
  4. 33.06㎡×1戸の用途（オーナー住戸/管理人室/一般賃貸）はどれですか？

物件仕様・確認事項

  1. 浜野町の路線価倍率表を国税庁で確認して積算比率を確定させる（IG+暫定値7万円/㎡で計算中）
  2. 火災保険は水災付き必須（洪水・高潮浸水想定区域内）。融資金融機関の水害減額有無も要確認
  3. 施工会社の実績（同規模木造3階建の竣工物件を3件以上）と第三者検査導入

🎯 チーム総合所見

総合判断

「基準外だが光る点多数・要検討」
駅徒歩2分×新築×売主取引×融資実績2行は極めて筋が良い案件。ただし①総事業費1.57億が基準1億超過、②浸水想定区域内の物理リスク、③前買主融資不成立の原因未解明——この3点をクリアできるかがGO判断の焦点。

最大リスク（優先順）

  1. 融資リスク: 1.57億円で1棟目としてオリックス/auじぶんが通るか未検証。前買主が融資不成立で流れた事実は物件評価に起因する可能性を否定できない
  2. ハザードリスク: 洪水・高潮浸水区域内（0.5〜3.0m）。標高3.7m低地。長期保有時の水害発生確率と保険料増額を織り込む必要
  3. 単一企業依存リスク: JFE製鉄所の生産構造改革（10-20年スパン）で賃貸需要が変動する可能性
  4. 建築リスク: 未着工・確認申請進行中。工期遅延・建築費上振れ・完成保証の設計が命

次のアクション（提案）

  • 【最優先】売主に「前買主融資不成立の詳細」を書面で照会 → 買主属性起因ならGO検討、物件評価起因なら見送り
  • 【並行】ケンジ先生に1.57億案件の融資可能性を事前打診（りそな・七十七・オリックス・auじぶん）
  • 【並行】路線価倍率表を国税庁で確認して積算比率を確定させる
  • 【条件付GO時】買付時に「建築確認取得を停止条件」「手付金保全」「建築費上限固定」の3点を必須
