🌅 ハルト（朝倉 晴斗）— エリア・利回り分析

キャプテン基準チェック

  • OK 築8年（≤10年）
  • OK 価格8,450万円（≤1億円）
  • NG 利回り6.72%（≥8.0%基準未達）
  • OK 川崎市多摩区（16号内側・一都三県）

エリアの将来性

  • 小田急小田原線『生田』駅は新宿まで直通約28分。急行停車駅の向ヶ丘遊園まで1駅で乗継良好
  • 明治大学生田キャンパス・専修大学生田キャンパスが至近 → 安定した学生需要
  • 川崎市多摩区は昼夜人口比率が低く（住宅地色が濃い）、単身向け1Kは学生・若手社会人の需要が中心
  • 川崎北部の住宅地として底堅い需要はあるが、賃料上昇余地は限定的

表面利回り6.72%の相場感

  • 多摩区・築8年木造1Kの相場は表面利回り6.5〜7.5%レンジ → 相場並み・割安感なし
  • キャプテン基準（8.0%以上）との差1.28ポイントは指値約6.9%（450〜500万円弱の指値）で解消できるが、売主受諾は難しい

空室リスク

  • 1K×8戸・現状満室稼働。生田駅8分は徒歩圏として無理なし
  • ロフト4.3帖付きで実質1DK相当の使い勝手 → 単身者に人気の間取り
  • 204号室2026.05に退室補修費計上 → 直近退去あり。募集状況と入居履歴の確認要
  • 周辺競合（明大生田キャンパス周辺）は多め。学期変わり目（3・9月）の空室リスクあり

ハルトの結論

新耐震・満室・生田駅8分と表面は綺麗だけど、キャプテン基準で見ると利回り6.72%は明確にNGだね。しかも今回は土砂災害レッドゾーンで即NGが出た以上、これは物件そのものを見送るしかない。
仮に指値で利回り8%圏に押し込めても、レッドゾーンの土砂リスクは金融機関の担保評価にも影響するし、将来の売却時にも足枷になる。
「築8年満室でキレイ」に惑わされずに、次の物件に切り替えたい。

🏗️ 村田 誠一 先生 — 建築士コメント

現場を見ないと断言はできませんが、資料から読み取れることを率直にお伝えします。

構造・工法

  • 1K×8戸+外階段+共用廊下型 → 在来軸組工法の可能性大
  • 2017年10月築 → 2000年基準（現行木造基準・最上位グレード）適合。壁量計算・N値法・接合部金物規定を全て満たす
  • スレート葺（コロニアル系）→ ノンアスベスト製品と推定。将来の葺替・処分費が通常のコロニアルより安く済む反面、経年で表面塗膜が痩せると割れやすい弱点あり
  • 絶対高さ制限10m以下に対し木造2階建（軒高6〜7m程度）→ 余裕あり

修繕リスク（築8年→直近5年）

  • 外壁塗装（シーリング打替）: 築10〜12年目 → 120〜180万円
  • 屋根スレート塗装: 築10〜15年目 → 40〜70万円
  • 給湯器交換（LPガス・8戸）: 築10〜15年目に順次 → 80〜120万円
  • 入退去時原状回復: 5〜10万円/戸
  • 直近5年の修繕予備費として300〜400万円確保推奨

中長期修繕（築13年以降）

  • 外階段・共用廊下鉄骨部塗装: 30〜60万円
  • 2回目外壁塗装（築20〜22年）: 150〜200万円
  • 屋根スレート葺替 or カバー工法（築30年前後）: 150〜350万円

法令適合性

  • 検査済証の有無を必ず確認
  • 建蔽率50%: 実測は1階水平投影面積÷土地面積で判定。2階建で1階約67㎡なら約48%と推定 → 適合の可能性大
  • 容積率100%: 延床134.71÷土地138.67=97% → 適合
  • 4m接道: 建築基準法接道義務クリア。ただし42条2項道路（みなし道路）の可能性ありセットバック要確認
  • 境界非明示 → 現地確認の最重要項目

現地必須確認8項目

  • ① 外壁シーリングの状態（築8年→そろそろ劣化開始）
  • ② 屋根スレートの浮き・欠け・苔
  • ③ 共用外階段・共用廊下の鉄骨部サビ
  • ④ 給湯器（LPガス）の製造年・設置場所 → 一斉交換タイミングの見極め
  • ⑤ ロフト梯子・手掛りの安全性 → 入居者事故時のオーナー賠償責任
  • ⑥ 境界杭の現存・越境物（樹木・エアコン室外機・雨樋）
  • ⑦ 床下（基礎点検口）・小屋裏（天井点検口）の目視 → シロアリ・雨漏り・断熱ズレ
  • ⑧ 戸境壁・上下階遮音性能（空室での実測）

村田先生の総合所感

2017年築・木造・2000年基準適合という条件は建築的には手堅い部類です。ただし木造アパートは築10〜12年目に必ず最初の大規模修繕サイクルが来ます。購入直後にこれが待ち構えている物件なので、購入価格8,450万円とは別に、直近5年で修繕予備費300〜400万円を必ず確保してください。
境界非明示・契約不適合免責という2点は買主側の事前調査で埋めるべき情報の空白です。ここを埋めずに買うと購入後にトラブルが来る可能性があります。
現場を見ないと断言はできませんが、資料上は「10年目大規模修繕を織り込めば長期保有に耐える手堅い建物」です。ただし今回のハザード結果（土砂災害レッドゾーン）は建物の質とは別の次元で見送り判断が正しいでしょう。
