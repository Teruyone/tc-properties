📊 ハルト（エリア・利回り分析）

エリア将来性

  • 京急本線「追浜」駅徒歩4分 — 品川直通で都心アクセス良好（品川まで約45分）。駅近好立地。
  • 日産追浜工場（EV拠点として再生産方針）・防衛大学校・湘南国際村エリアの単身社会人・工場勤務者・自衛官・大学院生の賃貸需要あり。
  • 横須賀市は人口減少局面（2020年40.9万人→2040年推計32万人程度・年▲1%）。追浜地区は特に高齢化が進行中。
  • 単身1K需要は日産工場・自衛官ローテーションに依存する景気連動リスクあり。

想定利回り6.57%の妥当性

  • 横須賀市・京急沿線・新築1Kは表面6.0〜7.5%が相場 → 6.57%は相場並み（売主の値付けは市場妥当）。
  • ただしキャプテン基準7.1%（新築）を明確に下回る。エリア×スペックの構造的問題で、値引き交渉でも埋まらない差。

空室リスク

  • プラス: 駅徒歩4分・新築・劣化等級3・独立洗面台・ロフト・宅配ボックス完備 → 空室戦略は組みやすい。
  • マイナス: 全8戸1K単身層一本足・専有17.47〜18.02㎡は狭小1Kゾーン・LPガス指定で光熱費割高・横須賀人口減少トレンド。

積算評価（概算）

  • 土地: 7.7万円 × 153.44㎡ = 1,181万円
  • 建物: 建築費約4,500万円想定 × 70% = 3,150万円（新築木造）
  • 積算合計: 約4,331万円 / 積算率48%（IG+の劣化等級3反映で58%まで押し上げ可）
ハルトの結論: 利回り面で見送り推奨。ただし追浜駅徒歩4分・新築の希少性は認めるので、指値7,800〜8,000万円で表面7.4%超まで交渉できるなら再検討したい。それが無理なら、同じ8,980万円の予算で別エリア（16号内側の京急・小田急・東急沿線築浅）を探す方が期待値が高い。

🏗️ 村田先生（一級建築士コメント）

構造・工法の評価

  • 各戸のスパンが1,820mm（1間）または3,640mm（2間）で構成 → 木造在来軸組工法として標準的でクセのない設計
  • 1F・2F平面がほぼ一致（総二階に近い）で直下率が高く耐震性能上有利
  • 断熱: 内部GW50φ/24K・屋根裏まで施工。準防火地域仕様として最低限は確保
  • 界壁: 両面石膏ボードt=12.5×2重貼り+屋根裏まで施工 → 遮音・防火の界壁仕様は法令準拠
  • 屋根: 5/10勾配（26.5度）寄棟。標準的で問題なし
  • ロフト（H≦1,400mm・小屋裏物置扱い）は容積不算入。夏場の暑さクレーム対策で天井断熱厚を現地確認推奨

法令適合性

  • 接道: 「公道 42条2項道」（市道41号）で確定。SB約1m済み。有効接道長さ約6.9m。
  • ただし反対側敷地の後退次第で実質幅員は2.2m〜3mの狭あい道路。工事車両搬入・引越しトラック・救急車両の進入に注意
  • 第1種高度地区: 最高高さ9.22m < 10m高度地区 → クリア
  • 準防火地域: 開口部EB認定品・強化石膏ボードt=12.5・軒裏軒天下地ボード → 防火性能は合格点
  • 宅地造成規制区域: 配置図に「切土・盛土なし」明記 → 造成擁壁リスク低。ただしCB9段H1800mmの控え壁・鉄筋補強が適法か現地確認必須
  • 建蔽率55.7%（60%以下）・容積率92.5%（200%以下） → 適合

劣化対策等級3級の意義

  • 75〜90年相当の耐久性能を担保 → 融資期間延長評価の可能性
  • 住宅性能表示制度による第三者検査が入り、施工品質が担保される（最大メリット）
  • 積算評価も24万/㎡で計算可能（IG+反映済）

修繕リスク（30年周期）

  • 5-10年目: 給湯器交換 80-120万 / 外壁シーリング 60-80万
  • 10-15年目: 外壁塗装・シーリング 150-200万 / 屋根点検・部分補修 30-50万
  • 20-30年目: 給水管更新 240-400万 / 排水管更新 160-320万 / 屋根葺替 150-250万

現地で必ず確認すべきこと

  1. 前面道路の実測幅員と後退線杭の位置
  2. 敷地境界杭の有無と隣地建物との離隔
  3. ブロック塀CB9段H1800mmの控え壁・鉄筋の有無（2018年大阪北部地震以降の所有者責任）
  4. 地盤調査報告書（追浜は丘陵地形。地耐力不足時の改良費100-300万は誰負担？）
  5. 建築確認申請書一式（耐震等級・断熱等級・住宅性能評価書の各種等級）
  6. 引渡時の完了検査済証と住宅性能評価書（設計・建設の両方交付を契約特約に明記）
  7. 施工中の場合は現場監理体制・施工会社の実績
  8. 界壁の遮音仕様・ロフト部の断熱厚（1Kアパートの最多クレーム源）
  9. 屋外階段の防錆処理（塩害エリア・溶融亜鉛メッキか塗装か）
  10. 土砂災害警戒区域の指定有無（丘陵地・宅造規制区域内）
村田先生の総合所見:
「現場を見ないと断言はできませんが」、意匠図を拝見した限り設計内容は木造1Kアパートとして標準〜やや上のクオリティで、大きな設計上の問題は見当たりません。むしろ好印象な点が3つ:①総二階に近い平面で直下率が高く耐震性能上有利、②劣化対策等級3級で第三者検査が入る、③準防火・界壁の遮音防火仕様が丁寧。この物件のリスクは「建物」ではなく「立地条件（狭あい道路・丘陵地形）」と「収益性」にあります。購入するなら「住宅性能評価書（設計・建設）の両方交付」「地盤改良費の負担明確化」「引渡時の完了検査済証提出」の3点を契約特約に必ず入れてください。
