リスクフラグ 🚩

🚩 リスク①（最大）：新築プレミア価格 vs 川越線沿線の実力 — 表面利回り7.00%は埼玉市街化区域・新築木造としてはギリギリ。スマサテ査定で1戸あたり実勢家賃を確認し、ズレが5%以上あれば実質利回り6%台に落ち即NG判定。

🚩 リスク②：新築プレミア剥落後の賃料下落 — 通常2〜3年で剥落し家賃5〜10%下がる。出口（築10年）で想定利回り7% → 6%程度まで落ちる可能性。

🚩 リスク③：売主一貫体制の「利益二重取り」構造 — 土地仕入〜設計〜施工〜販売〜管理まで全て自社。売主利益が価格に厚く乗り、中古売却時に価格が伸びない可能性。

🚩 リスク④：川越線・西大宮駅の賃貸需要 — 単線・本数少なめ（日中1時間3〜4本）、駅前商業集積が弱い新興住宅街エリア。ただし大宮直通8分は評価点。

🚩 リスク⑤：木造3階建の融資評価 — 準耐火建築物だが金融機関の積算耐用年数は22年（木造）。1.298億円にフルローンが出るか要確認。

🚩 リスク⑥：シロアリ・防蟻保証 — 新築木造の防蟻保証は通常5年。ケイアイスターの「建物10年保証」に防蟻が含まれるか要確認（別枠が通常）。

🚩 リスク⑦：ハザード（荒川低地） — 融資評価に直結（オリックス・地銀とも浸水想定3m超はNGにする傾向）。

アキからひとこと

1円単位で詰めましたが、率直に申し上げます — 「価格1億超え・利回り7.00%」で入口2指標が同時にNGです。1棟目FIRE戦略v5の「築10年以内・利回り8.0%・1億円」基準に真っ向から反する構成。

「現場を見ないと断言はできませんが、資料から読み取れることを35年の経験を踏まえてお伝えします」

構造・工法の評価

木造3階建て・準耐火構造・延床299.01㎡・1LDK×9戸。準耐火は耐火被覆（石膏ボード等）で主要構造部を45〜60分の火災に耐える処理で、木造3階建てとしては標準的かつ合理的な選択。ケイアイスターは分譲戸建て年間5,000棟以上のスケールで、構造計算・プレカット精度・現場管理は同規模ゼネコンより安定していることが多い。

劣化対策等級について

資料には「火災対策等級3」の記載はあるが、住宅性能表示制度における「劣化対策等級」の明示はなし。ただし間接的な劣化配慮として以下あり:

  • 強度ベタ基礎構造 → 湿気遮断・シロアリ抑制（劣化等級2以上の要件を実質的に満たす仕様）
  • グラスウール法定4倍厚 → 結露リスク低減（壁体内結露は木部腐朽の主因）
  • 準耐火構造の石膏ボード被覆 → 木部の直接露出を防ぐ

キャプテンへの提案: 売主に「劣化対策等級」の取得有無を必ず確認。等級3が取得されていれば融資評価・売却時評価が明確に上がる。

火災対策等級3・防音仕様の実効性

  • 火災対策等級3: 建築基準法の1.5倍相当
  • 界壁: 石膏ボード2重貼り → 遮音性能D-45〜50期待
  • 防音フロア: クッション材+軽量気泡コンクリート36mm → LL-45〜50相当
  • 遮熱複層ガラス: 冬季結露リスク低減・光熱費訴求

仕様書通り施工されていれば「木造アパートは音が響くから嫌」というトラウマ入居者にも訴求できるレベル。

法令適合性の確認ポイント

  • 建築確認番号「第HPA-25-09445-1号」は民間確認検査機関の交付形式
  • 用途地域: 第一種住居地域 → アパート用途OK
  • 接道: 公道 南東4.00m → 建築基準法上の道路幅員クリア
  • 建蔽率・容積率: 167.15㎡土地に299.01㎡建物 → 容積率179%（一種住居地域指定容積率200%想定なら問題なし・要都市計画図確認）
  • 斜線制限: 3階建て木造は北側斜線・道路斜線が効きやすい → 設計図で天空率・斜線検討書を確認したい

必ず取得すべき書類: 建築確認申請書（副本）／検査済証／住宅性能評価書／構造計算書／地盤調査報告書・地盤保証書

売主一貫体制物件（ケイアイスター）ならではの注意点

プラス面: 品質バラツキ少・アフター窓口一本化・10年建物保証+20年地盤保証は業界標準以上・スケールメリットで坪単価抑制。

マイナス面:

  • 分譲戸建てが本業 → アパート専業ビルダー（アイケン等）と比べると賃貸運用ノウハウは薄い可能性
  • 自社管理システム理解を条件 → 管理会社が実質固定される
  • 10年保証は書面通りだが、5年目・10年目の定期点検内容の実効性を先に確認
  • 竣工前物件のため、実際に建った棟の入居実績・退去率が未蓄積の可能性

現地で必ず確認すべきこと（10項目）

  • ① 基礎の立上り・水切り（土台と地盤面の距離40cm以上）
  • ② 外壁のシーリング施工状態（打ち込み深さ・プライマー処理）
  • ③ 界壁が屋根裏まで貫通しているか（天井点検口から目視）
  • ④ バルコニー防水の立上り・排水口（FRP立上り15cm以上）
  • ⑤ 共用階段・廊下の材質（鉄骨orアルミ推奨・木製NG）
  • ⑥ 玄関ドア・防火ドアの認定シール
  • ⑦ 床下換気口・小屋裏換気口の位置と数
  • ⑧ 敷地内の水勾配・雨水排水（基礎周りの湿潤防止）
  • ⑨ 隣地との離隔距離（雨水跳ね返り・北側斜線）
  • ⑩ 建物と隣地境界の間の防蟻処理範囲（1m以内標準）

3階建て木造アパートの特有リスク

  • 斜線制限ギリギリ設計: 3階の2〜3戸に居住性の妥協がある可能性。図面で3階天井高を確認
  • 耐震性: 2000年基準以降なら基本問題なしだが、構造計算書と限界耐力計算書を必ず入手
  • シロアリ: 防蟻処理は5年保証標準。保有期間中2〜3回の再処理費用（1回20〜30万円）を見込む
村田先生の総合所感: 資料ベースでは大手ビルダーの新築1LDK×9戸として仕様レベルは合格ライン。グラスウール4倍厚・軽量気泡コンクリート36mm床・界壁石膏ボード2重貼りは木造アパートの弱点（断熱・遮音）を意識した実効的な仕様。
リスクは建物側より、事業性（利回り・管理・出口）側にあるというのが率直な所感です。
