ハルト（エリア・利回り分析）

結論: 見送り推奨（ハザードリスク＋利回り不足＋16号外側の三重苦）

1. キャプテン基準

  • 築10年以内 ✅（新築） / 1億円以内 ✅ / 首都圏 ✅
  • 利回り8.0%以上 ❌（資料7.06%・新築基準7.1%も未達）
  • 16号内側 ❌（我孫子市は16号外側）

2. エリアの将来性

  • 我孫子市総人口 約13.1万人（緩やかな減少）・高齢化率31%（全国平均超）
  • 我孫子駅（JR常磐線快速停車駅）1日乗降客約2.8万人・上野東京ラインで東京駅40分
  • つくし野7丁目は駅遠住宅街・戸建て中心。徒歩16分は入居者層が限定される

3. 利回り相場感

  • 一都三県16号外側の新築木造アパート実勢：8.0-9.0%
  • 近隣類似（松戸市平賀 3,380万 6.95% 徒歩15分・16号内側）に対し、我孫子16号外側で同利回りは割高

4. 空室リスク

  • 20㎡×4戸：単身若年層・学生向け。我孫子駅圏の学生需要は限定的
  • 資料賃料45-49k/月は駅遠を織り込んだ弱気設定。スマサテ査定60,695円との乖離は「本当に取れるのか」要検証

5. ハザードリスク（最重要）

  • 浸水10-20mは即NG基準を5-10倍超過。事業継続性そのものを脅かす
  • 火災保険水災補償は必須かつ高騰（年10-20万円+α）
  • 出口（売却）で買主の融資審査でも減点対象

ハルトの一言: 「スマサテ考慮利回り8.57%は魅力的だが、資料値との乖離21%は上振れシナリオ。加えて浸水10-20mは致命的。同じ3,400万を出すなら松戸市・柏市の16号内側で駅徒歩10分以内の物件を探した方が期待値は圧倒的に高い。」

リョウ（DD）

リスクレベル: 高

確認済み ✅

  • 建築確認済証（第26UDI1W建00699号・令和8年5月7日交付）
  • 接道: 位置指定道路 42条1項5号（S39.8.19指定 No.211）幅員4.0m 延長38.3m → 現行法上の再建築可否はクリア
  • 用途: 長屋（4世帯）→ 共同住宅ではなく長屋扱い（消防・避難規定の緩和メリット）

🔴 最大リスク: 洪水浸水想定 10.0m〜20.0m

  • オリックス銀行: ハザード審査でほぼNG想定
  • 神奈川銀行・auじぶん銀行: 10-20m浸水想定は未知数
  • 滋賀銀行: 無担保枠なら物件担保審査回避できるが、3,400万は無担保枠上限（1,500万）超過 → 単独使用不可
  • 水災補償: 5等地（最高料率）確定・年間保険料は通常の2〜3倍
  • 出口リスク: 買い手も同じ融資ハードルを踏む → 流動性リスク大

🔴 地耐力データが仮定値

  • 建築確認済証に「近隣データ又は行政指導による地耐力を参考に構造計算」と明記
  • 実地盤調査は着工前 → 地盤改良必要時の追加費用が売主・買主どちらの負担か契約条項で明確化必須

🟡 その他のリスクフラグ

  • 位置指定道路の所有形態（共有か位置指定のみか）が未確認
  • 完成前売買（青田売り）→ 手付金保全措置・引渡し遅延違約金・完成保証の確認必須
  • 20㎡×4戸の狭小長屋 → 新築プレミアム剥落後の空室リスク
  • 「985番7、985-1の一部」の"一部"表記 → 分筆前提・土地面積確定時期の確認要

未確認・要入手

  • 地盤調査報告書・地盤改良施工結果報告書

村田先生（建築士コメント）

「現場を見ないと断言はできませんが」を口癖に、35年のキャリアからの所見。

1. 構造・工法

  • 新耐震・2000年基準クリア済み。木造在来か枠組壁工法かは図面で要確認
  • 長屋4連戸の戸境壁（界壁）は小屋裏まで達する遮音構造が法令要求（施行令114条）→ 検査時立会でチェック
  • 20㎡プランでバス・トイレ別・洗面独立・室内洗濯機置場が全て収まっていれば十分戦えるプラン

2. 地盤リスク（最重要注意点）

  • 手賀沼流域・標高5.7m → 軟弱層が数m〜10m前後堆積している可能性が高い（沖積低地・後背湿地の典型）
  • 地盤改良費想定: 表層改良50-80万円 / 柱状改良120-200万円 / 鋼管杭250-400万円
  • 売主が地盤改良費を負担する契約条件か、必ず確認
  • 村田先生の肌感覚: 「柱状改良120-200万円は覚悟しておくべき」

3. 修繕リスク（10年時点）

  • 外壁塗装＋屋根＋バルコニー＋給湯器 = 190〜280万円
  • 修繕積立を月2万円×12ヶ月＝24万円/年 確保しておけば10年目の大規模修繕は自己資金なしで回せる
  • 20㎡狭小プランの原状回復は1戸5〜8万円で収まる（メリット）

4. 法令適合性

  • 位置指定道路（S39年指定）は再建築可能。ただし現況幅員4.0mの実測・位置指定図の写しを市役所で取得推奨
  • 延長38.3mの袋路状道路 → 転回広場の有無確認
  • 必ず検査済証取得を売買条件に組み込む

5. 洪水リスク（建築士的見解）

  • 浸水10m＝木造2階建ての屋根まで完全水没・20m＝ビル6-7階相当
  • 設備の10m以上への配置は物理的に不可能 → 「浸水したら設備全滅」を前提とした事業計画
  • 水災補償は必須・年間15-25万円想定・5年一括払い推奨
  • 「新築だから安心、はこの物件では通用しない。土地値評価＋長期出口戦略が要」

6. 現地・完成後の必須確認項目

  • 地盤改良施工結果報告書（改良工法・杭本数・N値・支持層深度）
  • 基礎（配筋写真・立上りGL+400mm以上）
  • 躯体（中間検査記録・耐力壁配置・接合金物）
  • 屋根材・外壁通気層・バルコニーFRP防水
  • 界壁が小屋裏まで達しているか
  • 分電盤・給湯器の設置高さ（浸水対策）
  • 検査済証原本の受領

キャプテンへの確認事項まとめ

  1. 【最優先】滋賀銀行の融資可否 — 洪水浸水10-20mを受けて、滋賀銀行に既に打診済みか？NG時の代替戦略は？
  2. 火災保険（水災補償込み）の見積取得済みか？年間15-25万円で実質利回りが6%を切る可能性
  3. 土地面積の確定 — 「985番7、985-1の一部」の"一部"表記。分筆時期・土地面積確定時期を確認
  4. 売主評判 — Brain Trust from The Sun（中上和則氏／大川氏）の取引履歴・業界評判・決算状況
  5. 賃貸市場ヒアリング — 我孫子駅徒歩16分・20㎡×4戸の管理会社ヒアリング済みか？スマサテ査定60,695円が本当に取れるか
  6. 地盤改良費の契約条項 — 売主・買主どちらの負担か、契約書で明確化を
  7. 青田売り契約条件 — 手付金保全措置・完成保証・引渡し遅延違約金
  8. 位置指定道路の権利関係 — 道路所有形態・通行掘削承諾書取得可否

チーム総合所見

🚫 見送り推奨（4名一致）

4名全員が「見送り推奨」で一致しました。理由は以下の通り:

致命的リスク（見送り理由）

  1. 洪水浸水想定10-20m — キャプテン即NG基準（2m以上）の5-10倍。融資・保険・出口の全てに深刻な影響
  2. 我孫子市は16号外側 — キャプテンのエリア基準外
  3. 資料利回り7.06%はキャプテン基準（8.0%）未達 — 新築基準7.1%すら未達

スマサテ賃料版で見た場合の光る点（参考）

  • スマサテ査定ベース利回り8.57%は基準クリア
  • 積算比率76.8%は好材料
  • 路線価9.2万円/㎡（D60%）で担保余力あり

ただしスマサテ賃料が実現しない可能性

  • 資料賃料 vs スマサテ査定の乖離21% — 駅遠エリアでこの賃料が本当に取れるか要検証
  • 新築プレミアム剥落後（3-5年目）の空室リスク
  • 実際は資料賃料前後で落ち着く可能性が高い

キャプテンへの提言

本物件は「浸水10-20mが致命傷」です。仮に滋賀銀行の融資が付いても、10年後・20年後の出口で買い手が同じハザード問題を踏む構造で、資産価値の下落リスクを長期に抱えることになります。

同じ3,400万円の予算であれば、松戸市・柏市・流山市の16号内側で駅徒歩10分以内・洪水浸水2m未満の物件を探すことを強く推奨します。滋賀銀行との関係構築が目的であれば、ハザードクリアな別物件で打診するのが本筋です。

なお、7月12日（日）12:00〜のオンライン面談（Brain Trust from The Sun 中上氏）は、売主評判・青田売り条件・地盤改良費の負担条項を確認するヒアリング機会として活用する価値はあります。ただし買付はハザードクリア＋滋賀銀行融資可否＋実勢賃料ヒアリングの3点が揃うまで見送るべきです。
