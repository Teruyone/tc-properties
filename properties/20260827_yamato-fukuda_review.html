📍 ハルト（エリア・利回り分析）

エリア分析

  • 桜ヶ丘駅（各停停車のみ）：横浜駅まで約26分、新宿方面直通あり。マイナー駅だが徒歩圏の生活利便性は良好
  • 桜ヶ丘駅乗降客数: 1日18,849人（2024年度・小田急70駅中51位）
  • 周辺人口: 22,966人・10,920世帯（2025年推計）。5年前対比 人口▲314人・世帯数+492 → 単身化進行・総人口は減少フェーズ
  • ファミリー層中心、桜丘小・幼稚園徒歩5分圏、大和市は待機児童ゼロ継続、治安良好
  • 賃貸相場: ワンルーム4.7〜6.7万円、1K 6.2万円、2DK/2LDK 7〜10万円

ハルト評価

プラス材料
  • スマサテ考慮利回り8.72%は資料8.3%を上回り、賃料前提は健全
  • 駅徒歩7分・平坦地・スーパーあり・小学校徒歩5分でファミリー需要は堅い
  • ハザードマップ完全クリア（標高56.6mの内陸台地）
  • 1億円以下・6,680万円は買いやすい価格帯
マイナス材料
  • 築37年鉄骨造 → キャプテン基準「築10年以内」を27年オーバー（最大の壁）
  • S銀行100%・金利3.8%・35年は極めて重い条件。築37年で残存耐用短く、実融資期間は15〜20年に短縮される可能性大
  • 積算比率54%（土地3,630万 vs 価格6,680万） → 純積算は弱め
  • エリア人口減少フェーズ（5年で▲314人）
  • 1K 15㎡は超狭小、賃料上限4.2万円で頭打ち、原状回復コストが賃料に対して重い
  • 築37年鉄骨造 → 今後10年で外壁・屋根・給排水の大規模修繕発生確実
ハルト判定: キャプテン基準では見送り推奨。同じ大和で新築・築浅の別物件を探すのが投資効率上有利。

🔍 リョウ（DD・デューデリジェンス）

リスクフラグ 🚩

  • 法定耐用年数超過による減価償却切れ + 融資期間タイト：重量鉄骨（34年）想定でも耐用超過。減価償却枠極小・売却時の次買主融資リスク
  • 高金利によるCF圧迫：S銀行3.8%・35年でも空室2戸で赤字転落
  • エリア需給リスク：桜ヶ丘駅は各停・郊外・駅力弱め。2DK×6戸の需給要精査

  • 建物老朽化：外壁・屋上防水・給排水・受水槽・消防設備すべて更新時期
  • 鉄骨の錆・耐震補強：溶接部劣化・骨組み発錆リスク

法令適合性の要確認

  • 検査済証の有無：1988年築の投資用アパートは無いケースあり。無いと融資評価・確認申請でハンデ
  • 建蔽率・容積率適合（土地252.51㎡/延床283.2㎡・容積率112%相当）

  • アスベスト含有建材（1988年築は外壁・軒天・保温材で使用可能性大）

現地必須チェック（一級建築士推奨）

  • 外壁クラック・鉄骨露出部の錆・基礎の白華現象
  • 屋上防水膨れ・パラペット笠木浮き・最上階の天井シミ
  • メーターボックス内の給水管材質（白ガス管か塩ビライニング鋼管か）
  • 受水槽・増圧ポンプの製造年、共用部モルタル剥離、消防設備点検記録
  • 境界標の全数確認、隣地越境物
村田総合所感：現場を見ないと断言はできませんが、築37年鉄骨造は「これから10年、金と手間がしっかり必要な建物」です。今後10年で1,300〜2,300万円の修繕を織り込むと実質利回りは1.5〜2.5pt下がる。実質6%前後で回るならアリ、8%欲しいなら価格指値600〜1,000万円の建築的根拠あり。

まず「重量鉄骨か軽量鉄骨か・検査済証・給水管材質」の3点を最優先確認。ここが真っ黒なら見送り。

結論

キャプテン基準9項目中6項目でNG。特に「築10年以内」を27年オーバー、CF率・CCR・積算比率・10年目IRRいずれも基準未達。表面利回り8.3%（スマサテ8.72%）だけは達成しているが、S銀行3.8%×築古融資期間短縮リスクにより実CFは赤字〜トントンレベル。

最大リスク（3点）

  1. 融資期間短縮リスク：S銀行提示35年は築37年鉄骨に対し非現実的。実務では20〜25年短縮の可能性大 → CF ▲61.9万〜▲125万/年
  2. 減価償却切れ＋修繕爆弾：法定耐用超過で税務メリットなし。加えて今後10年で1,300〜2,300万円の修繕が確実
  3. 出口戦略の詰まり：築37年で購入・築47年で売却時、次買主が融資付けできず売却困難

次のアクション（3択）

  1. 推奨: 見送り。同エリア（大和市・座間市・海老名市）で築10年以内・木造アパート・利回り8%物件を再サーチ（ハルトが動きます）
  2. 再検討条件: 価格5,500万円以下まで指値できる場合のみ再検討（土地実勢3,630万+建物残価500万＝4,130万円ベースで指値根拠あり）
  3. 徹底確認シナリオ: それでも購入を検討する場合は、レントロール・修繕履歴・確認済証・給水管材質・鉄骨種別の5点セットを取得の上、村田先生と現地立会いで再精査
