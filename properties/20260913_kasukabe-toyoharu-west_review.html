ハルト — エリア・利回り分析

キャプテン基準（v5）との照合

新築・8,550万円・利回り7.20%はキャプテン基準（新築6%以上）を大幅にクリア。ただし春日部市は国道16号外側のため、エリア基準では基準外。他の項目は全て基準内で、エリア基準の壁を越えれば化ける可能性があります。

春日部市・豊春駅の実力

  • 豊春駅（東武アーバンパークライン=野田線）: 各停のみ停車の中規模駅。1日乗降客数 約9,800人（2024年度）
  • 人口動態: 春日部市は緩やかな人口減少（約22.7万人・年▲0.5%）。ただし駅徒歩10分の下蛭田エリアは新築アパート供給が続く単身者需要圏
  • 通勤アクセス: 豊春→大宮20分（春日部乗換）／豊春→北千住40分／豊春→柏30分。大宮通勤圏として単身賃貸需要は堅い
  • 開発計画: 春日部駅高架化事業（2031年完成予定）→ 東西動線改善で春日部エリア全体の利便性向上見込み
  • 賃貸需要（1K単身）: スマサテ分布（100戸データ）で51,000〜84,000円と幅広く、平均帯（59,000〜66,000円）に36戸集中 → 単身需要は健全

表面利回り7.20%の相場感

春日部市の平均利回り: 楽待7.01% / 健美家6.79%（築新〜築浅木造アパート平均）。本件7.20%は市平均より高め。ハウスリンクは自社土地仕入れ・建築・販売・管理を一貫することで中間マージンを抑制。「関係会社案件のため丁重返信推奨」の裏づけと整合。

空室リスク・物件競争力

  • 1K単身者向け9戸・大宮通勤需要を狙う設計。オートロック・宅配ボックス・2口IH等の設備水準は現代標準以上
  • 徒歩4分にコモディイイダ豊春店・徒歩1分に東武ストア豊春店（深夜0時まで）→ 生活利便性◎
  • 専有20.56〜24.40㎡は戸ごとにバラつき。狭小戸（20.56㎡）は査定より下振れの可能性あり
  • 近隣仲介からは「大宮通勤者からの需要見込みあり」との情報（資料より）

ハルトの率直な評価

「16号外」の壁を一つ越えれば化ける可能性大。
推し材料3点:
  1. スマサテ+8.77%上振れ → 資料7.20%が実質7.83〜8.21%相当。新築で1割近い賃料余力は珍しい
  2. ハウスリンク姉妹シリーズ実績 → 自社ですでにカインドネスシリーズ保有（八王子大塚C棟等）。設備仕様・管理体制の中身がわかっている物件
  3. 売主直（仲介手数料ゼロ） → 諸費用4%程度で済み、法人設立中のTC Asset Frontierとの相性◎
懸念材料3点:
  1. 16号外（春日部・大宮通勤圏で単身需要は健全だが出口が首都圏内側より難）
  2. 洪水浸水0.5〜3m → 浅い側だが、1階居住なら水損リスク顕在
  3. 9戸で少し多め（キャプテン目安6〜8戸を+1超過）
次の一手案:
A案（前向き検討）: 20.56㎡の狭小戸で再スマサテ → 下振れ確認、融資はauじぶん銀行（95%）想定で叩き台作成
B案（丁重返信）: 「16号外につき見送りだが、姉妹シリーズとして情報提供感謝」→ HLM松本様との関係維持
関係会社案件という属性を踏まえると、B案でも「なぜ見送るか」を明示的に丁寧に返した方が長期リレーション上プラス。

リョウ — DDチェック

確認済み（問題なし）

  • 新耐震基準: 新築のため当然クリア
  • 接道義務: 北側7.3m公道4.6m接道（1項1号）・西側5.9m公道12.3m接道（4項3号）→ 充足
  • 取引態様: 売主 → 仲介手数料不要（諸費用約4%）
  • 構造・築年: 木造3階建て新築（耐用22年フル取得可）
  • 満室想定賃料: 年615.6万円（月513,000円÷9戸＝1戸あたり月57,000円平均）

リスクフラグ

🚩 最大リスク① — 建築条件付き土地の内訳妥当性
  • 土地3,000万円（114.88㎡）→ ㎡単価261,140円／坪単価約86.3万円
  • 建物5,550万円（210.27㎡）→ ㎡単価263,946円／坪単価約87.3万円
  • 木造新築の建築費相場は木造3階建て共同住宅で㎡25〜28万円が目安。建物価格は概ね妥当だが、土地・建物比率が売主意向で決まっており第三者チェックなし
  • 減価償却の観点では建物比率65%（5,550/8,550）は悪くない
→ 対処: 春日部市下蛭田の路線価6.8万円/㎡ × 114.88㎡ = 781万円が路線価ベース。実勢価格3,000万は路線価比3.8倍と高値。近隣取引事例を要検証
🚩 最大リスク② — 西側接道が4項3号
  • 幅員5.9mだが「4項3号」表記 → 特定行政庁指定の6m未満道路・セットバックが必要な場合あり
  • セットバックによる有効宅地面積の減少 → 建蔽率・容積率の再計算が必要
  • 分筆後114.88㎡から数㎡減少する可能性
→ 対処: セットバック後の有効面積を春日部市建築指導課に照会。既に建築確認取得済みなら影響は建物価格に織り込み済み
🚩 最大リスク③ — 管理委託契約・プロパンガス契約の縛り
  • ハウスリンクマネジメント（HLM）と管理委託契約締結必須 → 自主管理・他社委託不可
  • プロパンガス契約もHLM系列指定 → 給湯器・エアコンの無償貸与とセットの可能性（LP業者が設備費をガス代に上乗せ→入居者ガス代高騰→退去増）
  • 管理費率が相場（3〜5%）より高い可能性 → 収支圧迫
  • 解約条件（違約金・年数縛り）が売却時のネックになる
  • プロパン契約: 15年縛り＋中途解約時に設備買取義務がよくある
  • 2027年4月施行のLPガス商慣行是正省令により設備の無償貸与＝ガス代上乗せは法令違反となる可能性
→ 対処: 管理委託契約書ドラフト・LP契約書ドラフトを契約前に必ず全文入手。「解約条件」「違約金」「設備所有権の帰属」「入居者ガス単価」を精査
⚠️ リスク④ — 分筆後予定地積での契約
現状「332番2」は分筆未完了。114.88㎡は分筆後の予定値。実測で減少するリスク。契約書に「実測減少時の代金減額条項」がないと買主負担。
→ 対処: 契約書に「引渡し時実測」「1㎡以上の減少で代金精算」条項を必ず入れる
⚠️ リスク⑤ — 売主直販＝第三者チェック不在
仲介業者による契約書ドラフトチェック・重要事項説明の客観性が担保されない。
→ 対処: 司法書士（あかり合同事務所 齋藤先生）に契約書ドラフトのリーガルチェックを必ず依頼
フラグ⑥ — 洪水浸水想定（0.5〜3m）
春日部市は江戸川・古利根川氾濫リスクエリア。本地点は浅い側（0.5〜3m）で即NGレベルではないが、1階を非居住用途にする設計かどうかを売主に確認

未確認・要入手

  • 建築確認済証（済み or 未取得か）
  • 建築請負契約書ドラフト
  • 管理委託契約書ドラフト（HLM）
  • プロパンガス契約書ドラフト＋設備貸与条件
  • レントロール（想定家賃の根拠・近隣賃料事例）
  • 公課証明書（分筆完了物件があれば参考値）
  • 土地の重要事項説明書（分筆進捗・接道詳細）
  • 修繕計画（新築だが10年目大規模修繕の予備費想定）

総合判定

リスクレベル: 中〜高
物件スペック自体は「新築・木造3階建・1K×9戸・徒歩10分・売主直販」で悪くない。ただし本件は建築条件付き土地＋管理縛り＋プロパン縛り＋分筆前＋4項3号接道＋売主直販という「契約書リスクの塊」。数字（利回り7.20%）は新築基準を大幅にクリアするが、契約書3点（建築請負・管理委託・LP）のドラフトを全文精査するまでは絶対にGOを出せません。特に管理委託とプロパンの解約条件次第では、将来の売却時にバイヤーが嫌がって流動性が落ちる可能性あり。

アキのコメント

キャプテン基準を高く通過するオリックス想定・条件付きOKの神奈川銀行想定。 表面7.20%・新築木造・売主取引（諸費用4%）と、入口はキレイに通る。オリックスフルローンならCCR25.87%とAランク、CF率もクリア。神奈川銀行案はCF率1.67%Bで良好だが自己資金1,197万円が重くCCR11.94%で基準未達。1棟目フルローン戦略ならオリックス一択の並び。
NOI利回り5.39%・返済比率63.66%はキャプテン基準65%の内側ギリギリで、募集AD/固都税/管理費の一つでもズレると簡単に届かなくなる。積算は路線価6.8万/㎡で60.8%とギリクリア。スマサテ賃料が実現すれば利回り8.21%まで伸び、余裕度が一気に上がる。

村田先生 — 建築士コメント

「現場を見ないと断言はできませんが、資料から読み取れることを率直にお伝えします。新築の建築条件付き土地案件は『設計図で全てが決まる』ため、契約前のこのタイミングでのご相談は非常に賢明です。」

構造・築年評価

  • 延床210.27㎡ ÷ 9戸 = 1戸あたり約23.4㎡（共用部込み）。専有20.56〜24.40㎡なので、共用部（廊下・階段・PS等）は延床の約8〜10%程度と読める。狭小1Kにしては効率的な平面計画
  • 建蔽率チェック: 建築面積≒70㎡ ÷ 敷地114.88㎡ = 建蔽率約61%。第一種中高層住居専用地域なら建蔽率60%（角地緩和で+10%）で成立可能。ギリギリの設計
  • 容積率チェック: 210.27÷114.88 = 約183%。容積率200%以上の用途地域が必要（第一種中高層60/200想定と符合）
  • 木造3階建て共同住宅は建築基準法27条・法別表第1により1時間準耐火建築物以上が必須。壁・柱・床・梁・階段すべてに準耐火被覆が入るため、施工費が2階建てより約10〜15%割高
  • 2025年改正建築基準法（4号特例縮小・省エネ基準義務化）にも適合するはず。木造2階以上も構造関係規定の審査対象

遮音性・居住性

木造3階の遮音性はRC比で明確に劣る。特に上下階の重量床衝撃音（LH）は最大の弱点。TVI's（遮音マット）施工の有無は要確認。仕様変更交渉の余地あり（建築条件付きのメリット）

法令適合性の確認ポイント

最重要: 西側4項3号接道（幅員5.9m）
建築基準法42条4項3号は「特定行政庁が指定する幅員6m未満の道」。通常はセットバック（後退）が必要な場合がある。春日部市建築指導課に電話1本で「4項3号指定道路のセットバック要否」を必ず確認。仮に0.05〜0.5m×12.3m後退が必要なら敷地面積が0.6〜6.15㎡減少し、建蔽率60.9%→63.7%（10㎡減で危険）となる可能性。北側7.3m公道（1項1号）は問題なし。角地緩和（建蔽率+10%）が使えている可能性大。
  • 用途地域: 春日部市下蛭田は第一種中高層住居専用地域（60/200）の可能性が高い（要確認）
  • 斜線制限: 第一種中高層なら北側斜線10m+1.25の勾配。3階建て（高さ約9m前後）は北側境界からの離隔次第で成立
  • 日影規制: 第一種中高層は日影規制対象。高さ10m超で規制。3階建ての軒高が9m台に収まっているか要確認
  • 準防火地域: 春日部市下蛭田は指定なしの可能性が高い（郊外住宅地）。ただし法27条により1時間準耐火建築物は強制
  • 消防設備: 延床210㎡なので自動火災報知設備は通常不要だが、各戸に住宅用火災警報器必須。消火器（150㎡以上）・誘導灯（3階建て以上）必須

プロパンガス契約 — 2027年法改正リスク

ハウスリンクマネジメントとのプロパンガス契約締結必須。2027年4月施行のLPガス商慣行是正省令の観点で要精査。給湯器・エアコンの無償貸与＝入居者ガス代への上乗せは法令違反となる可能性。契約書上の設備の所有者・費用負担の明記を必ず確認。

現地で必ず確認してほしいこと

  • 西側公道（4項3号）の現況幅員実測: メジャー実測で5.9m確認・道路中心線・セットバック済み区間の有無
  • 分筆前の元地の状況・境界標: 確定測量済みか・分筆登記完了予定日
  • 隣地との高低差・擁壁: 高低差50cm以上ならCB擁壁の種類確認・宅造規制対象の可能性
  • 上下水道・電気の引込: 上水20mmだと9戸には不足・25mm必須・可能なら40mmで直結増圧
  • プロパンガス設置場所と契約条件: 2027年法改正の観点で必ず確認
  • 周辺の日照・通風・眺望: 南側・東側の建築計画（将来3階建てが建つか）
  • 売主直販対策: 引渡し前に第三者建築士のインスペクションを入れる（費用15〜20万円）

総合所感

プラス評価:
  • 木造3階建て9戸で敷地114.88㎡（34.75坪）という設計は、土地効率を極限まで引き出した「事業用地マックス活用型」
  • 2025年改正法対応の新築なので、耐震・省エネ・構造計算の信頼性は35年前・25年前の中古と比較して圧倒的に高い
  • 建築条件付き土地なので、契約前に仕様変更の交渉余地があるのが最大のメリット。遮音材・給湯器グレード・LAN速度あたりは交渉して詰めてほしい
  • ハウスリンクホーム（一級建築士事務所東京都知事登録第63765号）で設計・施工・販売・管理を自社完結の実績
懸念点:
  • 西側4項3号接道は春日部市の運用確認が第一関門
  • 建蔽率61%は角地緩和ありきの計画。確認申請書での角地認定が確定しているか要確認
  • 売主直販ゆえの第三者チェック不在リスクは、第三者インスペクションで補完すべき
  • プロパンガス契約義務は2027年法改正で経済合理性が変わる可能性あり
35年運営を見据えた一言: 新築時から年間40〜60万円の修繕積立を内部留保する意思決定さえできれば、木造3階建て9戸は築20年目までCF機（キャッシュ生成マシン）として機能。ただし築25年超で構造材の劣化点検、築30年超で大規模リノベーションか建替判断が必要。ハルトが言う「利回り7.2%が新築でこの立地なら妥当」の裏には、この修繕コストを織り込んだ実質利回りが6%前後まで下がる現実があることを、ぜひ収支計算に反映してください。

建物は正直者です。設計図と現地を丁寧に照合すれば、必ず答えを教えてくれます。契約前の第三者インスペクション、強く推奨します。
