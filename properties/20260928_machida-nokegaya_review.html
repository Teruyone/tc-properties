🏘️ ハルト（エリア・利回り分析）

結論: 見送り推奨（★イチオシならず）

  • 鶴川駅エリア: 小田急小田原線・1日乗降客数約48,000人・新宿37分。鶴川駅前地区再整備事業（2028年完了予定）はプラス材料だが、大規模再開発は無し。人口は緩やかに減少・65歳以上比率28%超で高齢化進行。
  • 利回り7.09%の妥当性: 都下新築1Kアパートの相場は6.8〜7.8%。鶴川徒歩10分以内・新築1Kは概ね7.0〜7.5%。7.09%は下限ラインで割安感なし。むしろ相場並みかやや高値寄り。
  • 賃料70,667円の妥当性: 鶴川徒歩6〜10分・新築1K・20㎡の実勢は65,000〜75,000円。中央〜やや上寄り。新築時は妥当だが、2〜3年目の▲3〜5%下落を織り込む必要あり。
  • 空室リスク: 中程度。和光大学・玉川学園前の学生需要と単身社会人需要はあるが、鶴川駅徒歩10分圏内に新築〜築5年の1K供給20棟超で競合激化。町田市の1K空室率は8〜10%（都心5〜6%より高め）。
  • 決定打3点: ①レッドゾーン即NG、②利回り新築基準7.1%に0.01%不足、③エリア成長性頭打ち。

総合結論: 極高リスク（実質NG）

🔴 5大リスク

  1. 土砂災害特別警戒区域（レッドゾーン） — 融資否認リスク大（オリックスはほぼ不可）、保険料増、出口流動性低下、重要事項説明書に明記必須。
  2. 私道29名共有（持分33/980） — 掘削承諾・補修合意の形成困難。将来の相続で共有者枝分かれリスク。「通行掘削承諾書取得予定（地番1152-6/1152-2）」は取得完了を停止条件化必須。
  3. 造成中・分筆前・地番未定 — 令和9年3月下旬完成予定までの資金拘束期間が長い。引渡し遅延の違約条項確認必須。既存石積み擁壁の既存不適格リスク。
  4. 接道2.2m（S B無し） — 建築基準法2m接道義務は形式クリアだが極めてタイト。将来の建替え・売却で融資が付きにくい要因。
  5. プロパンガス — ランニングコスト増（都市ガス比1.5〜2倍）、女性単身層敬遠、家賃査定の下押し要因。

🏗️ 村田先生（建築士コメント）

「現場を見ないと断言はできませんが」

構造・工法・劣化等級3の評価

  • 木造2階建て・4号建築物相当。令和9年3月竣工なら新2号建築物として構造計算が求められる可能性大。
  • 延床123.24㎡÷6戸＝20.5㎡は共用廊下・階段込みで極めてタイト。低層住居専用地域で建築物のプランに無理をしている可能性。
  • 劣化対策等級3は品確法の最高等級（概ね75〜90年もつ配慮）。フラット35Sや長期優良住宅の入口条件で融資・出口価格両面プラス。ただし「設計」と「施工」は別物。竣工検査で防蟻塗布・通気層・水切り施工を必ず確認。
  • シロアリ保証が5年間しかない点は不自然（一般は10年主流）。等級3なのに5年？と首をかしげる点。

⚠️ レッドゾーン新築の適法性（最重要）

  • 土砂災害防止法第24条により、レッドゾーン内の居室のある建物は「想定衝撃力に対して構造耐力上主要な部分が損壊しない構造」が必須。通常はRC造の外壁または待受け擁壁が必要。
  • 建築確認番号「第20265BC-昭第00841H号」発行済みなので形式上は適法確認済。しかし「木造2階建て」でレッドゾーン内に居室のある建物を建てるには、土砂衝突想定面がRC造でカバーされているか、あるいは待受け擁壁が別途設置される計画になっているか、必ず確認する必要あり。
  • 資料の「既存石積み擁壁」は土砂法の待受け擁壁として認定されたRC構造物ではない可能性が高い。
  • 現地・書類での必須確認:①土砂法第24条適合図書（安全証明書・構造計算書）、②想定衝突方向の外壁がRC造 or 待受け擁壁があるか、③急傾斜地崩壊危険区域の指定有無、④町田市建築指導課での第三者確認。

既存石積み擁壁のリスク

  • 写真の既存擁壁は「練石積み」「空石積み」「大谷石積み」のいずれかの可能性。空石積み・大谷石積みは現行基準では認められないためRC造・L型擁壁への打ち直しが必要（㎡あたり10〜15万円）。
  • 販売図面に「既存石積み擁壁あり」とサラッと書かれているのが最も嫌な兆候。プロなら「築○年・種別○○・検査済証あり」と書く。書けないのは書きたくないか、書くと問題が明るみになる可能性がある。
  • 確認必須: ①擁壁の所有区分（重要事項説明書）、②高さ・築年、③維持補修責任の帰属、④将来の再構築費用（高さ2〜3m×長さ10mで200〜400万円）。2m超で検査済証なし＝買ってはいけない。

修繕リスク・費用概算

直近5年基本なし。ただし擁壁点検・補修50〜200万円の可能性。給湯器初期不良1〜2件。
5〜10年外壁塗装・シーリング打替 120〜180万円 / 屋根塗替 30〜80万円 / 給湯器交換15万×台数。
10〜20年大規模修繕 200〜300万円 / 給湯器一斉90万円 / FRP防水再施工60〜120万円。
20年〜給排水管交換180〜300万円 / 擁壁全面打ち直し300〜700万円（既存石積み旧基準なら確実発生）。

村田先生の結論

「土砂法適合図書」と「擁壁検査済証」の2点が書面で確認できない限り、購入は絶対に見送るべき。この2点さえクリアなら他のマイナスは価格交渉と運用でカバー可能。逆に、この2点でグレーが残るなら、いくら利回りが良く見えても手を出してはいけません。
35年の経験で「造成中の斜面地・既存擁壁・レッドゾーン」の三点セットで実際に土砂災害・擁壁崩壊のトラブルを起こした案件を複数見てきました。建物は正直者。土地の悪さは、いつか必ず建物に現れます。

🚨 見送り理由

  • 土砂災害特別警戒区域（レッドゾーン）該当 → キャプテン基準で即NG。融資否認・保険料増・出口流動性低下の三重苦。
  • 表面利回り7.09%が新築基準7.1%に0.01%不足 → レッドゾーンリスクを取るなら8%超のプレミアム利回りが必要なところ、逆に基準割れ。
  • 私道29名共有（持分33/980） → 掘削承諾・補修合意の形成困難、相続で更に細分化リスク。
  • 既存石積み擁壁の詳細不明 → 検査済証・種別・築年が資料に一切記載なし。旧基準なら300〜700万円の再構築費用発生確実。
  • 造成中・分筆前・地番未定 → 引渡し遅延リスク、長期資金拘束。
  • 接道2.2m・プロパンガス → 出口価格の減価要因が積み重なる。

🔀 例外的に進める場合の条件

  • 指値を6,000万円台前半まで下げる（表面利回り8%超確保）
  • DDリスト記載の停止条件10項目を全て契約に盛り込む
  • 擁壁実績のあるauじぶん銀行・神奈川銀行に事前照会し融資可否確認
  • 土砂法適合図書・擁壁検査済証の書面取得（村田先生確認）
